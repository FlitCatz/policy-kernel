# Historical documentation archive

This archive preserves dated plans, specifications, execution records, and
reviews. Their statements about implementation status, test results, open work,
and approvals describe the revision and time named in each document.

Use [Current status](../status.md) for the repository-wide latest summary and
[Task index](../tasks/README.md) to find the canonical landing page for a Task.
Do not rewrite an archived record to make it match later results; add a new status
or execution document instead.

- `plans/` contains dated implementation plans.
- `specs/` contains dated design and scope proposals.
- `reviews/` contains integration, validation, and review records.
- `superpowers/` retains dated agent-oriented plans and specifications.
